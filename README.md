# Sentinel AI

Marketing site for **Sentinel AI**: scoped security assessments in three phases (Recon → Scoped Assessment → Remediation and Retest).

## Stack

- Next.js 15 App Router
- Design tokens and globals adapted from Ascend Maui / Agent Overlord (`tokens.css`, `globals.css`)
- Dark / light / high-contrast themes

## Develop

```bash
npm install
npm run dev
```

## Deploy

Vercel project linked to this repo (same pattern as Agent Overlord’s `site/`).
